# ESP32 的其他用途

> 一块 ESP32-S3 除了控制跑步机，还能做很多事。本文按性价比排序。

---

## 一、零成本扩展（只需要改 YAML）

### 1.1 `bluetooth_proxy` —— 全家蓝牙覆盖

```yaml
esp32_ble_tracker:
bluetooth_proxy:
  active: true
```

**作用**：把 ESP32 变成一个蓝牙中继，Home Assistant 可以控制/读取**任何**蓝牙设备，不管它在哪个房间。

| 场景 | 说明 |
|---|---|
| 蓝牙门锁 | 门在楼下，二楼也能控制 |
| 蓝牙体重秤 | 站上去自动记数据，不用开 App |
| 蓝牙心率带 | 跑步时心率进 HA |
| 小米温湿度计 | 直接读，不用米家 |
| 蓝牙血压计 | 老人用，数据自动同步 |

### 1.2 已有现成组件的设备

| 设备 | 组件 | 备注 |
|---|---|---|
| 小米温湿度计 | `xiaomi_ble` | LYWSD02 等 |
| Airthings 空气质量 | `airthings_ble` | |
| RuuviTag | `ruuvi_ble` | |
| ThermoPro 温度计 | `thermopro_ble` | |
| Mopeka 气罐液位 | `mopeka_ble` | 烧烤煤气罐 |

| 蓝牙信号强度 | `ble_rssi` | 判断人在哪个房间 |

## 二、低成本硬件扩展（¥3-50）

### 2.1 红外遥控（¥5，性价比最高）

**让老家电变智能**：空调、电视、风扇、投影仪。

```yaml
remote_transmitter:
  pin: GPIO4
  carrier_duty_percent: 50%

remote_receiver:
  pin: GPIO5
  dump: all          # 学习遥控器信号用

climate:
  - platform: climate_ir_lg    # 换你的品牌
    name: "客厅空调"
```

**支持的空调品牌**：格力、美的、大金、海尔、LG、三菱、松下、日立…

**学习遥控器**：开 `remote_receiver` 的 `dump: all`，按遥控器，日志里会打印编码。

### 2.2 传感器

| 传感器 | 测什么 | 价格 | 组件 |
|---|---|---|---|
| DHT22 / SHT30 | 温湿度 | ¥10 | `dht` / `sht3xd` |
| BME280 | 温湿度+气压 | ¥15 | `bme280_i2c` |
| **SCD40/41** | **CO₂** | ¥80 | `scd4x` |
| MH-Z19 | CO₂（便宜） | ¥50 | `mhz19` |
| PMS5003 | PM2.5 | ¥50 | `pmsx003` |
| **HLK-LD2410** | **毫米波人体存在** | ¥30 | `uart` 自定义 |
| 光敏电阻 | 照度 | ¥2 | `adc` |
| 水浸 | 漏水 | ¥5 | `binary_sensor` |
| 门磁 | 门窗 | ¥3 | `binary_sensor` |

**重点推荐 HLK-LD2410**：毫米波雷达，能检测**静止的人**（PIR 检测不到坐着不动的），做「人在自动开灯」非常准。

### 2.3 继电器（控制家电电源）

| 能做 | 成本 |
|---|---|
| 灯 | ¥5 |
| 排气扇 | ¥5 |
| 热水器/加湿器 | ¥10（大功率需固态继电器） |

⚠️ **220V 有危险**，建议用成品模块（Sonoff、涂鸦）或找电工。

### 2.4 其他有意思的

| 功能 | 组件 | 用途 |
|---|---|---|
| LED 灯带 | `esp32_rmt_led_strip` | WS2812 氛围灯 |
| OLED/LCD 屏 | `ssd1306`, `ili9xxx` | 显示温湿度、日历 |
| 称重 | HX711 | 宠物粮余量、咖啡豆 |
| 舵机/步进 | 原生 | 自动窗帘、喂食器 |

| MQTT 桥 | 内置 | 接任何 MQTT 设备 |
| Modbus | `modbus_controller` | 光伏逆变器、工业设备 |

## 四、ESP32 做不了什么

| 不行 | 原因 | 替代 |
|---|---|---|
| 视频/音频处理 | 算力不够 | 树莓派 |
| 大量设备同时主动连接 | BLE 连接数上限 3-5 个 | 多块 ESP32 |
| 长期数据存储 | 无磁盘 | HA / 数据库 |
| 复杂逻辑 | YAML 表达力有限 | HA 自动化 / Node-RED |
| **5GHz WiFi** | 只支持 2.4GHz | 确认路由器有 2.4G |
| Zigbee/Z-Wave | 需额外协调器芯片 | 独立 USB dongle |

### 关键限制：BLE 连接数

| 模式 | 上限 |
|---|---|
| **主动连接**（`ble_client`，如跑步机） | **3-5 个** |
| **被动监听**（`esp32_ble_tracker`，如温湿度计广播） | **几十个** |
| `bluetooth_proxy` 转发 | 不占主动连接名额 |

**所以**：如果要同时控制跑步机 + 门锁 + 体脂秤，可能需要 2 块 ESP32。

## 六、一块板能同时干的事

```yaml
esp32_ble_tracker:              # 被动监听（温湿度计、体脂秤）
bluetooth_proxy:                # 转发给 HA
  active: true

ble_client:
  - mac_address: AA:BB:CC:DD:EE:FF   # 跑步机

sensor:
  - platform: xiaomi_ble          # 小米温湿度计
  - platform: dht                 # 阳台温湿度
    pin: GPIO6

remote_transmitter:               # 红外
  pin: GPIO4

climate:
  - platform: climate_ir_lg       # 空调
```

**一块板 = 跑步机控制器 + 蓝牙网关 + 温湿度计 + 空调遥控器。**
