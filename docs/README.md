## 快速路径

**如果你的跑步机也是 YPOO / 麦瑞克 / 佑美：**

1. 读 [02-FTMS协议参考](02-FTMS协议参考.md) 了解指令
2. 读 [04-踩坑记录](04-踩坑记录.md) 避开已知问题
3. 按 [05-ESP32刷机流程](05-ESP32刷机流程.md) 部署

**如果是其他品牌：**

1. 读 [03-抓包教程](03-抓包教程.md) 抓你自己的包
2. 用 `tools/parse-btsnoop.py` 分析
3. 参考 [01](01-协议逆向完整记录.md) 的方法论
